# R8EM Releases

This repository contains release binaries for **R8EM** (Run8 Enhancement Manager).

## About R8EM

R8EM is a tool for managing textures, mods, and enhancements for Run8 Train Simulator V3.

## Downloads

See the [Releases](https://github.com/sjstein/R8EM-releases/releases) page to download the latest version.

## Installation

1. Download `R8EM.exe` from the latest release
2. Download `UpdaterHelper.exe` from the same release
3. Place both files in the same folder
4. Run `R8EM.exe`

## Features

- Enhancement library management
- Profile-based enhancement switching
- Automatic backups of original files
- Auto-update functionality
