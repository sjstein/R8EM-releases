## R8EM - an "Enhancements" manager for Run8 Train Simulator

### NOTE: This software is in no way associated with Run8 Studios or the developers of the simulator.

### NOTE: The use of this software comes with risks as it copies files over your existing run8 texture and sounds files. No warranty on the operation of this software is implied. Use at your own risk. 
*You should ALWAYS keep a backup copy of your Run8 installation in a fresh state without any enhancements that you can return to easily if something goes wrong with this piece of software.*


## Downloading R8EM

The latest release can always be found on the right side of this repository. Within each release, you should find a zip file. Download that file and unzip the files within into a separate directory (for example, C:\R8EM)

R8EM will check for updates each time it starts.

Documentation can be found here: https://github.com/sjstein/R8EM-releases/blob/master/R8EM_User_Guide.md
